[[OSI 7 계층]]이란 네트워크 프로토콜 디자인과 통신을 7개의 계층으로 나누어 개념적으로 설명한 것입니다.  
OSI 7계층은 응용 계층, 표현 계층, 세션 계층, 전송 계층, 네트워크 계층, 데이터 링크 계층, 물리 계층이 있습니다.  

[[TCP IP 계층|TCP/IP 계층]]은 OSI 7 계층을 기반으로 상업적이고 실무적으로 이용될 수 있도록 단순화한 것입니다.  
TCP/IP 계층은 응용 계층, 전송 계층, 인터넷 계층, 네트워크 연결 계층이 있습니다.  

> [!QUESTION]- 왜 네트워크 통신을 계층으로 나누었는가요?
> 관심사와 책임을 분리하기 위해서 입니다. 각 계층이 정해진 인터페이스를 통해 동작하므로 특정 계층의 구현이 변경되어도 다른 계층에 미치는 영향을 줄일 수 있습니다. 또한 서로 다른 장비와 프로토콜 간의 표준화와 호환성이 쉬워집니다.  

> [!QUESTION]- 실제로 데이터를 전송할 때 각 계층에서는 어떤 일이 발생하나요?
> 송신 측에서는 상위 계층에서 하위 계층으로 내려가면서 각 계층의 헤더가 추가되는 캡슐화가 이루어집니다.  
> 수신 측에서는 반대로 헤더를 제거하며 상위 계층으로 전달하는 역캡슐화(디캡슐화)가 이루어집니다.
