## 개발 내용

### 좌표 기반 가까운 점포 조회

행정구역 경계와 관계없이 가까운 점포를 찾을 수 있도록, 지도 중심 좌표를 받는 조회 API와 MyBatis 쿼리를 구현했습니다.

- 위도·경도가 있는 점포의 거리를 SQL에서 계산하고 거리순으로 정렬했습니다.
- `ROWNUM`으로 응답 건수를 제한하고, 고정 10개에서 요청별 개수를 받는 방식으로 확장했습니다.
- 조회 결과를 지도와 점포 목록에 연결했습니다.

[조회 구현](https://github.com/yourjinKR/storemap2/commit/a7c7ac6) · [응답 개수 설정](https://github.com/yourjinKR/storemap2/commit/292f689)

### 지도 오버레이의 표시·선택 상태 관리

지도 확대 수준에 따른 표시 상태와 사용자가 선택한 항목의 강조 상태를 분리했습니다.

- 선택 오버레이를 `clickedOverlay`로 추적하고, 선택 변경 시 이전 항목의 강조를 해제했습니다.
- 일반 오버레이는 확대 수준과 지도 모드에 맞춰 표시하고, 선택 항목은 별도로 유지했습니다.
- `pointer-events`로 지도 조작과 오버레이 클릭 영역을 나누고, 새 검색 시 지도 객체와 선택 상태를 함께 초기화했습니다.

[선택·클릭 영역 구현](https://github.com/yourjinKR/storemap2/commit/f2bb536) · [검색 상태 초기화](https://github.com/yourjinKR/storemap2/commit/0c944b1)

### 점포·이벤트 자동완성 목록 갱신

점포와 이벤트의 비동기 검색 결과를 한 목록에 표시하면서, 각 유형의 결과를 독립적으로 갱신하도록 구성했습니다.

- 새 응답이 오면 같은 유형의 이전 항목만 교체하고 다른 유형의 결과는 유지했습니다.
- 검색 실행·입력·포커스 상태에 맞춰 자동완성 목록을 표시하거나 숨겼습니다.
- 방향키로 선택한 추천 항목과 일반 Enter 검색을 구분해 지도 조회에 연결했습니다.

[유형별 목록 갱신](https://github.com/yourjinKR/storemap2/commit/dfeea60) · [검색 후 목록 처리](https://github.com/yourjinKR/storemap2/commit/3c5c215)

### 주소 입력과 지도 위치 연동

이벤트 수정 화면에서 저장된 주소와 새로 선택한 주소를 같은 지도 객체에 반영하도록 연결했습니다.

- 기존 주소를 Kakao Geocoder로 좌표로 변환해 지도 중심과 마커 위치를 복원했습니다.
- 우편번호 검색에도 `basicMap`을 전달해 지도 참조를 통일했습니다.
- 새 위치 표시 전 기존 마커를 제거하고 주소·지도·마커를 함께 갱신했습니다.

[구현 커밋](https://github.com/yourjinKR/storemap2/commit/165aac0)
