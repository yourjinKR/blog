## 절차지향 언어

절차지향 언어는 프로그램을 일련의 순차적인 처리 과정으로 바라보는 방식입니다. 다시 말해, 프로그램이 수행해야 할 일들을 순서대로 나열하고, 각 작업을 독립적인 함수(프로시저)로 분리하여 작성합니다.  

- 순차적인 처리가 핵심이며, 프로그램의 흐름 제어가 중요함
- 함수가 프로그램의 기본 단위로 사용됨
- 데이터와 함수가 서로 분리되어 존재함
- 전체 코드의 구조가 단순하여 초보자에게 접근성이 좋음
- 코드의 재사용성이 낮고, 기능 중심 설계로 인해 유지보수나 확장에 한계가 있음
- 프로그램이 커질수록 함수 간의 의존성이 높아져 복잡도가 증가할 수 있음
