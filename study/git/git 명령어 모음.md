## 병합

```sh
git merge <병합할 브랜치>
```

병합시 vim 편집기로 제어 가능

![[IMG-20261111174643118.png]]

### 1. 기본 메시지로 저장하고 병합 완료하기 (가장 일반적)

1. 키보드의 **`Esc`** 키를 한두 번 누릅니다. (명령 모드로 진입)
2. **`:wq`** 를 입력합니다. (화면 맨 왼쪽 아래에 `:wq`가 적히는지 확인)
3. **`Enter`** 를 누릅니다.
    

_확인:_ 편집기 창이 닫히면서 터미널 기본 프롬프트로 돌아오고, `Merge made by the 'ort' strategy.`(또는 유사한 병합 완료 안내)가 출력됩니다.

### 2. 커밋 메시지를 직접 수정하고 싶을 때

1. 키보드 **`i`** 키를 누릅니다. (하단에 `-- INSERT --` 표시가 뜸)
2. 방향키로 이동하여 첫 번째 줄의 메시지를 원하는 내용으로 수정합니다.
3. 수정이 끝나면 **`Esc`** 키를 누릅니다.
4. **`:wq`** 입력 후 **`Enter`** 를 눌러 저장하고 종료합니다.
    

### 3. 병합을 취소(중단)하고 싶을 때

1. **`Esc`** 키를 누릅니다.
2. **`:qa!`** 입력 후 **`Enter`** 를 누릅니다. (저장하지 않고 강제 종료)
3. 터미널로 돌아온 뒤 아래 명령어를 입력하여 병합 전 상태로 되돌립니다
