MAC은 네트워크 통신에서 기기들이 랜선이나 와이파이 같은 물리적 통신 매체에 접근하는 방식을 제어하는 규칙이다.  

## MAC 주소

네트워크 인터페이스 카드(NIC) 제조 시 기기 내부의 롬(ROM)에 기록되며, 전 세계에서 유일한 값을 가진다.  

바이트(48비트)로 구성되며, 16진수 12자리로 표현한다.  

```
00:1A:2B:3C:4D:5E
```

라우터를 거치지 않는 동일한 네트워크 내부에서 데이터를 주고받을 때 최종적인 목적지를 찾는 용도로 사용된다.
