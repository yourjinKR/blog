# URI (Uniform Resource Identifier)

URI는 인터넷상의 리소스 **자원 자체**를 식별하는 고유한 문자열 시퀀스이다.  

- **Uniform**: 리소스를 식별하는 통일된 방식
- **Resource**: URI로 식별이 가능한 모든 종류의 자원
- **Identifier**: 는 다른 항목과 구분하기 위해 필요한 정보

> **URI**(Uniform Resource Identifier)는 하나의 리소스를 가리키는 문자열입니다.

> [!EXAMPLE]
> matchuri.com
