
## 면접준비

- 자바는 컴파일 언어이자 인터프리터 언어이다.
- 자바 컴파일러가 소스코드를 바이트 코드로 컴파일한다.
- 실행 엔진은 인터프리터와 JIT 컴파일러를 통해 실행한다.
- JIT 컴파일러의 캐싱 기준과 캐싱이 꽉 찼을 때는 어떻게 되는지 다시 생각하자.

## 모니터링의 Pull vs Push 모델

모니터링 시스템이 데이터를 수집하는 방식은 크게 2가지이다.  
Prometheus는 Push 모델이다.

- Pull: 서버가 모니터링 시스템에게 데이터를 보내는 방식
	- 장점
		- 이벤트 기반 데이터 전송에 유리
		- 방화벽 뒤에 서버도 데이터를 보낼 수 있다.
	- 단점
		- 서버 과부하
		- 서버 or 네트워크 문제인지 구분하기 어려움
		- 모니터링 대상 추가/제거시 각 서버의 설정을 변경 필요
- Push: 모니터링 시스템이 서버에게 데이터를 보내는 방식
	- 장점
		- 대상의 상태를 즉시 파악
		- 중앙 집중 설정 관리가 가능
		- 과부하 줄이기
		- 디버깅 용이
