title: 자바의 기본형(Primitive)과 참조형(Reference)의 메모리 저장 방식 차이에 대해 설명해주세요
tags:
  - 면접
  - 스터디
  - Java
---
기본 타입과 같은 경우는 스택 영역에 실제 값을 저장합니다. 
참조형 타입은 힙 영역에 실제 값을 저장하고 해당 메모리 주소를 스택 영역에 저장합니다.  

> [!QUESTION]- 꼬리질문
> 기본적으로 Wrapper Class 인스턴스의 값을 기본형 타입 변수에 값을 초기화 할 수 있습니다.   
> 그러나 Wrapper Class는 기본적으로 nullable하기에 만약 non-null한 기본형 타입을 대입시  
> `NullPointException`이 발생할 수 있습니다. 그 외에도 무분별한 사용시 성능 저하, 비교 연산자 사용시 논리 오류가 발생할 수 있습니다.
