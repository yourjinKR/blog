다중 서버 환경에서 세션을 각 서버의 메모리에 저장하면, 로그인한 서버와 이후 요청을 처리하는 서버가 달라질 때 세션을 찾지 못해 인증이 풀리는 문제가 발생합니다. 

해결 방법으로는 동일한 사용자를 같은 서버로 보내는 Sticky Session, 서버 간 세션을 복제하는 세션 클러스터링, Redis 같은 외부 저장소에 세션을 중앙화하는 방식이 있습니다. 

Sticky Session은 간단하지만 서버 장애와 부하 불균형에 취약하고, 세션 복제는 서버 수가 증가할수록 비용이 커집니다. Redis 방식은 수평 확장에 유리하지만 별도 인프라와 고가용성 구성이 필요합니다. 따라서 일반적인 분산 환경에서는 Spring Session과 Redis를 이용해 세션을 외부화하는 방식을 많이 사용합니다.
