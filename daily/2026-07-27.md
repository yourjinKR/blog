```groovy
implementation 'com.google.firebase:firebase-admin:9.10.0'
```

그러자 기존 `setToken()` 메서드가 deprecated

```java
private Message createMessage(String title, String body, String fcmToken) {  
    return Message.builder()  
            .putData("title", title)  
            .putData("body", body)  
            .setToken(fcmToken)  
            .build();  
}
```

![[Pasted image 20260727192328.png]]  

[Firebase 관리자 Java SDK 릴리스 노트](https://firebase.google.com/support/release-notes/admin/java)에 따르면 해당 `token` 필드는 사용하지 않고 `fid` 사용 권장 중이다. 그러나 fid는 기존에 사용하던 token과 다른 개념이기에 바로 대체할 수 없음.

- `setToken()`이 받는 값은 FCM 등록 토큰
- `setFid()`가 받는 값은 **Firebase Installation ID(FID)**

https://firebase.google.com/docs/admin/setup?hl=ko  
https://github.com/firebase/firebase-admin-java  

아직 FID으로의 변경이 얼마 되지 않았으니 일단 기존 토큰 방식으로 진행.

```groovy
implementation 'com.google.firebase:firebase-admin:9.9.0'
```

## 딥링크 실어보내기

```java
private Message createMessage(String title, String body, String fcmToken, Map<String, String> data) {  
    return Message.builder()  
            .setToken(fcmToken)  
            .setNotification(Notification.builder()  
                    .setTitle(title)  
                    .setBody(body)  
                    .build())  
            .putData("deepLink", "knockin://chat/rooms/123")  
            .putData("notificationId", "456")  
            .putData("type", "CHAT_MESSAGE")  
            .build();  
}
```

## 메세지 관리

인앱 알람
- 제목 - 정적 문자열 템플릿에 매개변수 넣어서 포맷팅
- 본문 - 정적 문자열 템플릿에 매개변수 넣어서 포맷팅

FCM 푸시 알람
- 제목 - 정적 문자열 템플릿에 매개변수 넣어서 포맷팅
- 본문 - 정적 문자열 템플릿에 매개변수 넣어서 포맷팅
- FCM 토큰 - 동적 문자열, `member`로부터 가져옴
- 딥링크 - 정적 문자열 템플릿에 매개변수 넣어서 포맷팅

> 현재 기준으로는 인앱과 푸시 알람의 제목/본문이 서로 같지만, 요구사항은 언제나 변경 가능하기에 강하게 결합해서는 안된다.
